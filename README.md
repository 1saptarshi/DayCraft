## 🧭 About DayCraft

**DayCraft** is not just a planner — it is a **daily life experience**.

Built with a strong focus on **premium UI/UX**, smooth animations, and practical workflows, DayCraft helps users organize tasks, habits, and schedules **without any backend, server, or admin panel**.

Everything runs locally. Everything feels fast.

---

## ✨ Why DayCraft?

- 📅 Plan days visually with an interactive calendar  
- ✅ Turn ideas into actionable tasks  
- 🔁 Build consistency through habit tracking  
- 🎨 Enjoy a clean, modern, distraction-free UI  
- ⚡ Zero backend. Zero setup. Instant performance  
- 💾 Your data stays on your device  

---

## 🚀 Features

### 📆 Calendar Module
- Monthly & daily calendar views  
- Highlight important or special dates  
- Add custom notes or labels to any day  
- Task & habit indicators inside the calendar  

---

### ✅ To-Do / Task Manager
- Create, edit, and delete tasks  
- Priority levels: **Low / Medium / High**  
- Mark tasks as completed  
- Filter tasks by date or status  
- Seamless calendar ↔ task integration  

---

### 🔁 Habit Tracker
- Add daily or weekly habits  
- Track streaks and consistency  
- Visual progress indicators  
- Habit completion history  

---

### 🎨 UI / UX Experience
- Mobile-first, responsive design  
- Smooth transitions & subtle animations  
- Minimal, focus-driven layouts  
- Modern color psychology & typography  

---

## 🛠 Tech Stack

| Layer        | Technology |
|-------------|------------|
| Structure   | HTML5 |
| Styling     | Tailwind CSS |
| Logic       | JavaScript (ES6+) |
| Icons       | Font Awesome |
| Storage     | LocalStorage / IndexedDB |

> 🚫 No backend  
> 🚫 No database server  
> 🚫 No admin panel

## 📦 Installation & Usage

```bash
https://github.com/1saptarshi/DayCraft.git
````


### 3️⃣ Run the application

* No server
* Works instantly
